# 📊 每日数据截图 CES 算法深度诊断与动态调优框架 (V5.0)

> **使用场景**：主理人每天截取上一篇笔记在【小红书创作者中心】的详细数据面板发送给 Sub Agent，Sub Agent 按照本框架做毫秒级诊断并直接输出下一篇笔记成稿。

---

## 一、小红书 CES (Content Evaluation System) 算法评分模型

小红书推荐流的核心打分公式为：
$$\text{CES Score} = \text{点赞} \times 1 + \text{收藏} \times 2 + \text{评论} \times 4 + \text{转发} \times 4 + \text{完播/阅读率得分} + \text{主页关注} \times 8$$

*注：评论、转发与主页关注的权重最高！收藏权重是点赞的 2 倍！*

---

## 二、四大关键指标红绿线与针对性诊断动作

### 1. 点击率 CTR（Click-Through-Rate：阅读数 / 曝光量）
*   🟢 **优秀 (> 12%)**：封面视觉张力极强，标题痛点扎心。**动作**：下一篇继续沿用同款封面构图与大字报句式。
*   🟡 **正常 (8% ~ 12%)**：处于健康基准线。
*   🔴 **预警 (< 6%)**：**致命短板在封面和标题！**
    - **诊断**：封面大字不够醒目，或者标题写得太像软文，未能激发点击欲望。
    - **下篇调优**：立即切换封面方案（改用荧光黄+亮红警示框，标题改用惊悚事实或反常识提问）。

### 2. 完播率 / 滑动完成度 (Completion Rate)
*   🟢 **优秀 (> 35%)**：正文节奏极佳，读者一字不差读完并滑到第 4 张图。
*   🔴 **预警 (< 20%)**：**致命短板在开篇前两行与段落过长！**
    - **诊断**：开篇两行没有立刻抛出冲突；段落堆叠太厚，缺乏断行和 Emoji。
    - **下篇调优**：前 3 行强制使用一句话短句 + 情绪词（“我整个人直接看傻了”），正文增加“看图2/看图3”引导读者滑动。

### 3. 藏赞比（收藏数 / 点赞数）
*   🟢 **优秀 (藏赞比 ≥ 1:1，甚至收藏 > 点赞)**：**顶级干货属性！**
    - **诊断**：读者认为此笔记具有极高的“工具工具箱属性”，必须存起来以后用。
*   🔴 **失衡 (赞多收藏极少，如 100 赞但仅 10 收藏)**：
    - **诊断**：情绪共鸣到位了，但**缺少可落地的干货资料包**，读者看完笑笑就走了。
    - **下篇调优**：必须强化【图 4】的行动诱饵，加大 Excel 模板、速算表或开源脚本的实用价值密度。

### 4. 评论互动率（评论数 / 阅读数）
*   🟢 **优秀 (> 3%)**：引流转化极高。
*   🔴 **预警 (< 1%)**：评论区冷场，读者没有打字欲望。
    - **下篇调优**：在正文结尾和首条置顶评论抛出“二选一投票”或“争议痛点”（例如：“大家觉得老外压价到底该不该给底线？”），主动降低评论门槛。

## 三、Sub Agent 每日交付闭环标准输出格式

当主理人上传截图后，Sub Agent 必须按以下标准结构即时输出：

```markdown
### 📋 上篇笔记数据复盘总评
- **曝光量**：[数字]
- **点击率 CTR**：[X%] ➔ [🟢/🟡/🔴] [针对性分析]
- **完播/停留**：[X%] ➔ [针对性分析]
- **互动情况**：赞 [X] / 藏 [X] / 评 [X] ➔ 藏赞比 [X:X]
- **核心瓶颈定位**：[明确指出是封面问题、开头问题、还是诱饵问题]

---

### 🎯 下一篇笔记自适应动态调度方案
- **调度决策**：[针对上一篇的瓶颈，决定本次发布：痛点打假图文 / 还是干货速算模板 / 还是粤语口播视频]
- **核心调整动作**：[如：针对 CTR 偏低，本篇全面升级封面黄色大字冲击力]

---

### 📝 下一篇笔记全套成品（可直接发布）
【4图轮播卡片设计指示 & HTML链接】
【彻底去 AI 味真人口感长文】
【置顶评论互动钩子】
```
