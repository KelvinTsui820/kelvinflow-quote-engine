1. 【导言与服务说明】

欢迎使用 KelvinFlow（以下简称“本平台”）。本平台是专为外贸业务员、跨境 SOHO 及出口制造企业打造的智能化外贸算价与询盘解析辅助工具。用户通过工作邮箱注册并启用本服务，即表示完全理解并自愿遵守本协议所有条款。

2.1 询盘要素解析：基于深度自然语言理解技术，对用户主动转发的外贸询盘邮件正文进行品名、型号规格、采购数量（MOQ）及国际贸易术语（Incoterms：FOB/CIF/CFR 等）的结构化抽取。

2.2 底价规则智能匹配：将抽取的询盘要素与用户私有上传的 Excel 底价表进行阶梯价位、关税加价、海运拼箱成本及汇率结算规则匹配。

2.3 商业单据草稿生成：基于匹配结果，自动生成符合国际商务标准的英文报价单（Proforma Invoice / Quotation Sheet）PDF 草稿，并投递至用户工作邮箱草稿箱。

3.1 用户私有数据绝对归属：用户上传的任何企业底价表（Excel/CSV）、产品规格明细、客户采购商名录及往来邮件正文，其知识产权与商业机密权利 100% 独家归属于用户或用户所属企业。

1. 【零密码侵入原则（Zero-Credential Intrusion）】

1.1 专属助理邮箱机制：本平台采用“专属助理邮箱智能转发（Mail-Forwarding）”机制运行，绝不索取、记录或存储用户企业邮箱、Gmail 或 Outlook 的账号登录密码，绝不要求获取任何邮箱 IMAP/SMTP 高危授权凭据。

1.2 绝不越权爬取信件：本平台绝不通过任何后台脚本扫描、爬取或遍历用户的企业通讯录、历史往来邮件及非询盘类商业机密信件。

2. 【商业底价表银行级加密存储与物理隔离】

2.1 存储加密：用户上传的 Excel 标准底价表在落盘时全部采用 AES-256 银行级算法进行不可逆哈希加密与数据块混淆存储。

2.2 租户级物理隔离：每个企业或用户的底价库建立独立的虚拟租户空间，杜绝任何跨账号的数据溢出、串读或索引污染，从根本上防止同行恶意刺探底价与截单。

3. 【海外买家询盘与客户线索绝对保密】

3.1 商业线索不倒卖承诺：买家邮箱、询盘产品规格、目标采购预算及企业贸易背景，仅在单次报价生成过程中调用。

3.2 严防商业截流：本平台绝不将用户的海外询盘商机用于任何形式的商业撮合、第三方商机推荐或行业数据打包变现。

4. 【数据自主权与彻底物理销毁】

4.1 数据自主可控：用户享有对自己全部商业资产的最高控制权，可随时在后台直接下载全部历史报价单据及底价配置。
