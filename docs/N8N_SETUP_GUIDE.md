# KelvinFlow · 全主流企业与个人邮箱自适应一体化 N8N 对接指南 (3 分钟白手套交付)

本文档专为 **一人公司创始人交付** 与 **企业客户 IT / 业务主管** 设计。通过全新的**全能一体化工作流 (`workflows/n8n-universal-all-in-one-quote-workflow.json`) v7 终极版**，实现单个工作流画布原生通吃 **企业邮箱（腾讯企邮、阿里、网易企业、Foxmail）** 以及 **个人邮箱（QQ 邮箱、网易 163/126、个人 Outlook/Hotmail、Gmail）**，无需为不同邮箱维护多套工作流，极度节省服务器内存并消除多版本维护成本。

## 🚀 3 步极速导入对接

### 第一步：在 n8n 中导入一体化工作流
1. 打开您的 n8n 实例（例如：`https://flow.kelvinflow.com/home/workflows`）。
2. 在右上角点击 **「Add Workflow」** 打开空白画布。
3. **极速导入（推荐）**：直接在空白画布上按下快捷键 **`Ctrl + V`**（剪贴板已为您复制好完整的 v7 工作流 JSON），整套 10 个节点和自适应连线将立即完整展现！
   *(亦可点击右上角三点菜单 ->「Import from File」-> 选择 `workflows/n8n-universal-all-in-one-quote-workflow.json`)*。

---

### 第二步：根据客户邮箱类型配置授权凭据 (Credential)

#### 方案 1：中小企业 / 外贸个人常用【QQ 邮箱、163/126 网易个人邮箱】
> **核心机制**：无需任何公网 API 申请，使用标准的 IMAP/SMTP 协议 + **16 位专用授权码**（安全且免维护）。

1. **获取 16 位授权码（1 分钟完成）**：
   - **QQ 邮箱**：登录网页版 QQ 邮箱 -> 点击顶部「设置」->「账户」-> 往下滚动找到「POP3/IMAP/SMTP/Exchange/CardDAV/CalDAV服务」-> 开启「POP3/SMTP服务」和「IMAP/SMTP服务」-> 根据提示发送短信获取 **16 位授权码**。
   - **网易 163/126 邮箱**：登录网页版 -> 点击顶部「设置」->「POP3/SMTP/IMAP」-> 开启「POP3/SMTP服务」和「IMAP/SMTP服务」-> 新增授权密码。
2. **在 n8n 中配置**：
   - 双击 **「1B. 通用 IMAP 监听入口」**：
     - **Host**: 
       - QQ 邮箱：`imap.qq.com`（端口 993，SSL/TLS 开启）
       - 163 邮箱：`imap.163.com`（端口 993，SSL/TLS 开启）
     - **User**: 客户的完整邮箱地址（如 `123456@qq.com` 或 `abc@163.com`）
     - **Password**: 上述步骤获取的 **16 位授权码**（切勿填 QQ/网易日常登录密码）
   - 双击 **「6B-2. IMAP/企业邮草稿箱同步与业务员待审信」**：
     - **Host**:
       - QQ 邮箱：`smtp.qq.com`（端口 465，SSL/TLS 开启）
       - 163 邮箱：`smtp.163.com`（端口 465，SSL/TLS 开启）
     - **User & Password**: 同样填入邮箱与 16 位授权码。

#### 方案 2：规范企业【腾讯企业邮 / 阿里企业邮箱 / 网易企业邮 / Foxmail】
1. 双击 **「1B. 通用 IMAP 监听入口」**：
   - **Host**:
     - 腾讯企业邮：`imap.exmail.qq.com`（端口 993，SSL/TLS 开启）
     - 阿里企业邮箱：`imap.qiye.aliyun.com`（端口 993，SSL/TLS 开启）
     - 网易企业邮：`imap.qiye.163.com`（端口 993，SSL/TLS 开启）
   - **User & Password**: 业务员企业邮箱及客户端专用授权码。
2. 双击 **「6B-2. IMAP/企业邮草稿箱同步与业务员待审信」**：
   - **Host**: 腾讯企业邮 `smtp.exmail.qq.com` / 阿里 `smtp.qiye.aliyun.com`（端口 465，SSL/TLS 开启）。

#### 方案 3：微软【Office 365 商业版 / 个人 Outlook / Hotmail】
> **注意**：微软已于 2024 年 9 月全面终止普通密码/应用密码（Basic Auth），所有个人 `@outlook.com`/`@hotmail.com` 与商业版均须采用 OAuth2。
1. 双击 **「1C. Microsoft Outlook 监听入口」**，新建或选择 `Microsoft Outlook OAuth2 API` 凭证完成点击授权。
2. 在 **「6B-3. Microsoft Outlook 草稿箱排入」** 节点中复用该 OAuth2 授权，系统将自动把报价单草稿存入业务员 Outlook 草稿箱。

#### 方案 4：海外与跨国客户【Google Workspace / Gmail】
1. 双击 **「1A. Gmail 监听入口」**，绑定该客户的 Gmail OAuth2 凭据。
2. 在 **「6B-1. Gmail 专属草稿箱排入」** 节点复用该授权。

### 第三步：配置 KelvinFlow 租户凭证与接口地址
工作流已通过 `$env` 环境变量实现了完全动态化，也可以直接在节点参数中填入：
- **目标服务域名**: `https://quote.kelvinflow.com` (或你的实际 VPS 域名)
- **请求头 `x-tenant-id`**: 该客户的企业专属租户 ID（例如：`tenant_fb32b6`）
- **请求头 `x-api-key`**: 该客户的企业专属 API Key（例如：`sk_live_a24875...`）

## 🛡️ 常见问题与细节处理

1. **发件方使用 QQ 超大附件（微云中转站链接）怎么办？**
   - 节点 **2B** 已内置正则识别器。当 QQ 邮箱买家附件超过 25MB 转为微云链接时，系统会自动在询盘文本中追加高亮提示：`[系统检测提示: 发件方通过QQ微云/网易中转站发送了超大附件链接: ...]`，业务员一目了然，无需担心遗漏设计图或大型 PDF。
2. **需要同时激活 1A、1B 和 1C 吗？**
   - 客户用什么邮箱就配置对应入口。例如客户是 QQ 邮箱或腾讯企业邮，只需配置 1B 和 6B-2，关闭或忽略 1A 和 1C 即可；若一个集团内既有 Outlook 团队也有企邮团队，可同时开启，0 号节点会自动识别渠道并精准分流！
3. **业务员如何 10 秒微调？**
   - 无论何种邮箱，草稿或待审邮件底部均包含：
     ```
     [📌 业务员在线核对与微调入口 (10秒极速修改)]: https://quote.kelvinflow.com/review/QT-xxxx?token=...
     ```
     业务员点开链接后，如遇临时调整折扣、加收运费或指定付款方式，滑动即可实时生效并自动重置正式 PDF！
